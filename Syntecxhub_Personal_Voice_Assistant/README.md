# Personal Voice Assistant

## Description

This project implements a Personal Voice Assistant using Python.

The assistant uses Speech Recognition to understand voice commands and Text-to-Speech to respond.

## Features

* Speech-to-Text
* Text-to-Speech
* Open Google
* Open YouTube
* Open Notepad
* Search the Web
* Tell Current Time
* Error Handling

## Technologies Used

* Python
* SpeechRecognition
* pyttsx3
* PyAudio
* Webbrowser

## How to Run

python voice_assistant.py

## Sample Commands

* Hello
* What is the time
* Open Google
* Open YouTube
* Open Notepad
* Search Python Programming
* Stop

## Output

The assistant listens to voice commands, performs the requested action, and responds using voice output.
