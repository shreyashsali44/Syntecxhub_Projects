# Rule-Based Expert System

## Description
This project implements a Rule-Based Expert System using Forward Chaining in Python.

The system:
- Accepts symptoms from user
- Uses IF-THEN rules
- Infers conclusions automatically
- Supports multi-step reasoning
- Displays inference steps

## Technologies Used
- Python
- Artificial Intelligence
- Forward Chaining

## How to Run

```bash
python expert_system.py
