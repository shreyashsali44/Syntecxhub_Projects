# Maze Solver using A* Search

## Description
This project implements the A* Search Algorithm to solve a maze/grid pathfinding problem.

The program:
- Represents maze as nodes
- Uses Manhattan heuristic
- Finds shortest path
- Handles unreachable cases
- Visualizes final path in console

## Technologies Used
- Python
- A* Search Algorithm

## How to Run

```bash
python maze_solver.py
